PenShot（story-shot-agent）是一个基于 LangGraph 的开源剧本分镜智能体：输入任意长度的剧本，输出可直接交给 Sora、Runway、Veo、可灵等视频模型逐段生成的分镜提示词包，并附带资产计划与模型路由结果。当前版本 v0.4.4。

功能定位

主流视频模型单次通常只能生成 5–10 秒画面，更长的成片需要先拆分剧本、逐段生成再拼接。PenShot 处理其中最容易出错的一步：把剧本拆成符合时长限制的片段，并让片段之间在角色、场景、道具和动作上保持衔接。

输入可以是自然语言剧本、标准剧本或已有分镜文本；输出是片段序列、每个片段的中英双语正向提示词与负向提示词、按能力匹配的模型路由结果，以及角色三视图 / 道具静帧 / 场景锚点的资产计划。视频生成、拼接与口型对齐由下游工具完成。典型用途包括短视频批量分镜、影视预可视化与游戏过场动画原型。

模型适配分两层：VideoModelType 枚举覆盖 Runway Gen-2、Sora、Veo、Pika、Midjourney、Stable、DALL·E 等 8 种基础模型；v0.4.3 起的模型能力注册表进一步收录 runway_gen4、kling_3、luma_dream、sora_2、pika_2，记录时长上限、是否支持图生视频、镜头控制、一致性与风格倾向。AudioModelType 覆盖 XTTSv2、AudioLDM_3、Bark、ElevenLabs、Azure TTS、OpenAI TTS，共 6 种。

八个业务节点对应 PipelineNode 中的 PARSE_SCRIPT、GENERATE_ASSETS、SEGMENT_SHOT、SPLIT_VIDEO、CONVERT_PROMPT、ROUTE_MODEL、AUDIT_QUALITY、CONTINUITY_CHECK。图中之外还有 HUMAN_INTERVENTION、ERROR_HANDLER、LOOP_CHECK、GENERATE_OUTPUT 四个控制节点；LangGraph 共注册 12 个节点（END 不是注册节点）。审计发现可修复问题时生成修复参数打回转换节点，连续性守护按问题来源动态路由回镜头拆分、片段切割或提示词转换。

阶段 节点 输入 → 输出 关键行为
剧本解析 parse_script 原始文本 → 结构化剧本 提取场景、角色、对话、动作，给出置信度与风格溯源
资产计划 generate_assets 契约 → 资产计划 / 回填清单 生成角色三视图、道具静帧、场景锚点规格；可选真实出图
镜头拆分 segment_shot 结构化剧本 → 镜头序列 按内容划分镜头，标注景别与时长
片段切割 split_video 镜头序列 → 视频片段 规则或 LLM 切分，继承连续性约束
提示词转换 convert_prompt 片段 → 提示词 逐片段生成双语正向词、负向词与音频提示词
模型路由 route_model 提示词 → 路由计划 / 适配包 按能力规则选模型，处理图生视频首帧与镜头控制
质量审计 audit_quality 提示词与路由 → 审查报告 11 项规则检查，输出违规条目与修复参数
连续性守护 continuity_check 全阶段产物 → 校验结论 视觉、角色、场景、动作四类校验，按来源路由修复

核心能力

能力 说明
剧本解析 识别场景、角色、对话与动作，输出结构化元素、解析置信度与全局风格锚点
资产计划 产出 AssetPlanDocument：角色三视图、道具静帧、场景锚点的提示词、尺寸、视角与使用范围；默认只声明计划，不调用外部服务
资产回填 接受 AssetManifest（bindings / asset_id_map），把声明式 asset_id 绑定到下游真实资产引用
镜头拆分 按内容划分镜头，标注景别、时长与主角色
双路径分段 ≤5.5 秒的镜头直接映射为片段，超阈值镜头交由 LLM 在语义边界切分；关闭 LLM 时按 2.5 秒左右等分
提示词工程 逐片段生成中英双语正向词、负向词与音频提示词，措辞跨片段复用，支持 RAG 模板召回
模型路由 静态能力注册表 + yaml 规则（默认 5 条），按文本复杂度、一致性要求、镜头运动与风格选模型，输出 RoutePlan 与 AdaptedPromptPackage
质量审计 11 项规则检查：片段时长、提示词内容与长度、片段数量、模型支持、外观锚点污染、契约违规、景别/镜头运动一致性、风格光照冲突、资产使用
连续性守护 一致性契约、资产锚点与修复回路：问题按来源路由回对应阶段，最多 3 轮修复
工程接入 13 个 SDK 方法、17 个 REST 端点、7 个 MCP 工具，任务池、检查点、三层记忆

输出形态

任务结果顶层为 task_id、status、success 与 data；data 下除 instructions 外，还包含 asset_plan、asset_manifest、asset_generation、audit_report、consistency_contract、continuity_issues、warnings 与 metadata.quality_gate。每个片段自带模型与风格字段，可独立投喂下游生成服务。

project_info 汇总片段数与总时长；route_plan 记录每个片段的目标模型、路由模式与被阻塞片段；asset_plan 是声明式生图指令，asset_manifest 是下游回填后的绑定结果。prompt 为英文描述加中文对照；negative_prompt 排除卡通、畸变手部、水印等常见瑕疵；audio_prompt 用 voice_type 区分旁白与角色台词，并以 previous_audio_id 串联上下文。样例落盘文件的字段名为 audio_prompt，当前 AIVideoPrompt 模型的字段名为 audio，写解析代码时以模型定义为准。

接入方式

方式 入口 说明
Python SDK create_penshot_agent()、PenshotFunction 13 个方法，含 asset_manifest / asset_manifests 参数；任务池默认并发 10、队列 1000
REST /api/v1，默认端口 8000 内置 FastAPI 服务，17 个端点，含提交、状态、结果、资产回填与队列观测
Docker neotems/penshot REST 服务的官方镜像，内置健康检查；Compose 可一并启动 Redis
MCP python -m penshot.mcp_server 7 个工具，默认 stdio 传输，breakdown_script 接受 asset_manifest
CLI story-shot-agent serve-rest 安装后启动 REST 服务，默认监听 0.0.0.0:8000

上述入口共用同一套任务池与工作流，任务状态与结果一致。接入细节见 集成指南 与 MCP 服务，容器部署见 Docker 部署。

当前边界

边界 说明
只产出提示词与资产计划 默认不生成视频；资产出图为可选项（image_generation.enabled 默认关闭），拼接、转场与口型对齐需外部工具完成
分割策略 镜头 ≤ 5.5 秒时走规则路径，通常 1:1 成为片段，不判断语义；超过阈值且 enable_llm=True 才交给 LLM 在动作停顿、句末等边界切分；关闭 LLM 时按 2.5 秒左右等分
时长校验 提示词建议单段不低于 1.5 秒、总时长误差小于 0.5 秒；代码强校验区间为 1.0–5.0 秒，总偏差超过 1 秒告警、超过 2 秒按比例缩放
修复闭环 审计与连续性检查均已接入动态修复路由，连续性修复最多 3 轮；超过轮次或存在阻断问题时转入人工干预
执行超时 工作流实际超时取 InputState.timeout，默认 600 秒；config.workflow_timeout=1800 仅在未传 timeout 时作为兜底
分割缓存 split_cache 为进程内字典，多副本部署时各自独立、无法共享命中
Redis 依赖 可选；不可用时短期记忆降级为本地文件，任务不中断，但多实例之间记忆互不可见

这些边界不影响“剧本 → 分镜提示词”主链路的可用性，但属于生产选型前应评估的部分。
