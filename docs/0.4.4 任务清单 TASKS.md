## 1. 执行约定

- 一次闭环只执行 **1–2 个任务**，完成后提交变更摘要并等待人工审查。
- 每个任务必须给出：改动文件、对应 AC、实际执行的验证命令与输出；失败如实报告。
- **M0 是硬门禁**：T-0001..T-0004 未全部完成前，不得开始 T-501..T-508 中任何与阈值相关的断言。
- 不新增工作流节点、不改 `workflow_pipeline.py` 拓扑、不新增 LLM 调用。
- 未经明确指令不执行 `git commit` / `git push`。
- 统一验证命令：

```bash
.venv/Scripts/python.exe -m pytest tests/unit -q
ruff check .
ruff format --check .
mypy src/
```
