Why PenShot

分镜的体力活，交给智能体

AI 视频模型一次只能生成 5–10 秒。要把两分钟的剧本变成成片，中间隔着几十次拆分、提示词编写与一致性校对。PenShot 把这一段自动化。

01 / 时长限制

剧本太长，模型吃不下

两分钟的剧本需要拆成几十个片段。切在哪里、每段多长，直接决定成片是否流畅。

智能分段与时长规划，输出模型友好的 5 秒级片段。
02 / 视觉漂移

角色换装、场景跳变

每个片段独立生成，角色长相、服装、场景光线很容易前后不一致，拼接后立刻穿帮。

一致性契约 + 连续性守护 + 修复回路，把一致性交给系统。
03 / 提示词工程

手写 Prompt 费时费力

每个镜头都要写画面、风格、负面词，还要兼顾不同模型的格式与时长偏好。

中英双语提示词包，正向、负面与音频提示词一次生成。

从原始剧本到可执行的分镜提示词包与资产清单，每一步都有明确的输入、输出与失败降级。

Capabilities

为分镜而生的工程能力

不只是一个提示词模板：记忆、检索、资产、路由、审查与多协议接入，都在同一条链路里。

Output

不是一段描述，
是一份可执行的分镜包

每个片段都包含正向提示词、负面提示词、时长、目标模型、视觉风格与音频提示词。中英双语，模型与人都能读。

  • 片段级提示词，可直接投喂 Runway、Sora、Veo、可灵
  • 负面词排除卡通、畸变手部、多余肢体与水印
  • 音频提示词包含环境音、角色台词、情绪与语速
  • 附带 asset_plan 与 route_plan，资产与模型选择可直接交给下游
  • 保留 task_id、一致性契约与质量门禁结果，分镜可双向追溯

Integrations

从 SDK 到容器，接进你的工作流

可以嵌入自有服务，作为独立服务运行，或挂给支持 MCP 的 IDE 与 Agent 客户端。

还提供 LangGraph 节点与 A2A 示例，详见 集成指南 →

python · sdk 
from penshot.api import create_penshot_agent

agent = create_penshot_agent(max_concurrent=5)

script = "早晨，一个女孩在咖啡馆读书，阳光透过窗户…"
task_id = agent.breakdown_script_async(script)

result = agent.wait_for_result(task_id)
print(result.data["instructions"]["project_info"])

Use cases

为这些创作场景准备

共同点只有一个：已经有一个文字剧本，想低成本、高连贯地变成视频素材。

短视频创作

把故事脚本变成日更素材

编剧或自媒体作者输入故事，直接得到可逐段生成的分镜提示词，缩短从文字到成片的距离。

影视预可视化

低成本完成分镜预演

独立电影人与学生剧组在正式拍摄前，用 AI 片段验证镜头节奏、场景与角色设定。

游戏剧情

快速原型过场动画

独立游戏开发者把剧情文本转成过场分镜，先验证叙事，再投入正式美术资源。

教育培训

把课程文字可视化

在线教育与知识付费团队将讲稿拆成镜头脚本，批量生成课程视频的画面素材。
