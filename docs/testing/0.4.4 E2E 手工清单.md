2. 历史模板完成 0.4.4 迁移，且已人工核对 dry-run 统计：
   ```bash
   python scripts/migrate_prompt_templates_044.py --script-id SN2183078837410690460926
   python scripts/migrate_prompt_templates_044.py --script-id SN2183078837410690460926 --apply
   ```

3. 记下本轮开始前的基线：`templates_cache.json` 条数与 `index_store` 文档数（供 AC-E2E-002/004 比较）。
4. 样本剧本：`SN2183078837410690460926`（雨中的约定）；输出目录 `tmp/output/<script_id>/<task_id>/`。

### AC-E2E-002 有历史模板时 anchor_recall 不得出现无解释 hits=0

查看结果文档 `metadata.anchor_recall`（运行时位于 `instructions.metadata`）：

- `status` 必须为 `hit` 或 `all_below_threshold`；其他取值需能由 FR-041 状态机解释（如 `retrieval_error` / `embeddings_unavailable`），否则判定失败。
- `kb.index_docs` 不得小于本轮开始前的缓存模板数。
- 注意：样本迁移后活跃模板为 0，首次重跑 `status` 会是 `empty_templates`，属冷启动（入库策略按 `cold_start_seed` 写入新模板）；以第二次重跑的结果判定本条。
- 结果：☐

### AC-E2E-003 asset_manifest 任务的引用语义

提交带 `asset_manifest` 的任务后检查 `asset_plan.json` 与各片段 `references`：

- `asset_ref` 只承载场景首帧（`role="first_frame"`, `as_first_frame=true`）。
- 角色三视图保留在 `references` 中（`role="identity_reference"`, `as_first_frame=false`）。
- 结果：☐

### AC-E2E-004 连续两次重跑的索引与缓存单调性

- 第二次运行的 `index_docs` ≥ 第一次；`templates_cache.json` 条数单调不减。
- 无「索引加载失败 → 单文档覆盖」导致的文档数骤降（0.4.3 缺陷特征：缓存 127、索引 1）。
- 结果：☐

### AC-E2E-005 两次输出均带风格溯源且无互斥打光

- 两次输出 `metadata.style_anchor_provenance`（workflow_nodes 写入 `instructions.metadata`）均存在且字段非空。
- `[Style: ...]` 前缀内 `soft warm` / `high contrast` / `low-key` / `natural` 最多命中 1 个族（≥2 即 FR-066 打光冲突），且不同时出现 `soft warm lighting` 与 `high contrast lighting`（AC-020）。
- 结果：☐
