# 资产提示词与下游接入

> 适用版本：`schema_version = 0.4.4`
>
> 本文说明 PenShot 输出的角色/道具/场景资产提示词如何交给下游节点，以及下游生成资产后如何把引用回填给 PenShot。

## 1. 边界与定位

PenShot 是剧本与视频生成之间的**中间节点**：

- 默认只产出**声明式指令**：资产提示词、片段引用、首帧指令、路由计划；
- **默认不调用**任何文生图 / 文生视频 API；
- 真实生图、生视频、二次修复由下游节点执行；
- 内置文生图客户端已降级为可选执行器（`AssetExecutionAdapter`），仅在显式注入或配置开启时使用。

这样下游可以自由选择图片/视频供应商，也可以在调用生成服务前修改提示词。

## 2. 下游能拿到什么

任务成功后，结果位于 `result.data`：

| 路径 | 内容 |
| --- | --- |
| `data.asset_plan` | 资产计划文档：角色三视图、道具、场景的声明式生图指令 |
| `data.instructions.asset_plan` | 同一份资产计划的指令集内嵌副本 |
| `data.instructions.route_plan.adapted_packages[]` | 每个片段的模型适配提示词包 |
| `…adapted_packages[].references[]` | 片段需要的资产引用（规范 `asset_id`、视角、是否首帧） |
| `…adapted_packages[].image_prompt` | 该片段所需的参考图提示词 |
| `…adapted_packages[].first_frame_instruction` | 给下游的首帧生成/使用指令 |
| `data.asset_manifest` | 若本次提交带了回填清单，则为回填后的清单 |
| `data.instructions.asset_manifest` | 同一份回填清单的指令集内嵌副本 |

### 2.1 asset_plan 示例

```json
{
  "schema_version": "0.4.4",
  "task_id": "t1",
  "script_id": "s1",
  "style_anchor": {"genre": "neo-noir", "description": "cinematic, moody lighting"},
  "assets": [
    {
      "asset_id": "char_001",
      "asset_type": "character_sheet",
      "owner_name": "林然",
      "image_prompt": "character reference sheet of 林然, front view, side view and back view, ...",
      "negative_prompt": "multiple characters, duplicate faces, ...",
      "size": "1024x1024",
      "views": ["front", "side", "back"],
      "usage": {
        "characters": ["林然"],
        "scenes": [],
        "fragments": []
      },
      "consistency": {
        "identity_lock": true,
        "preferred_view": "front",
        "seed": null
      },
      "status": "pending",
      "asset_ref": ""
    }
  ]
}
```

`status` 取值：

| 状态 | 含义 |
| --- | --- |
| `pending` | 仅有提示词，等待下游生成 |
| `generated` | 已回填真实 `asset_ref` |
| `failed` | 生成失败 |
| `skipped` | 已存在资产，本次跳过 |

`usage.fragments` 是该资产的**使用范围**：列出需要该资产的片段 ID。路由完成后会
按片段主角、场景地点、道具出现场景回填，并强制并入 `route_plan` 中显式引用的片段
（引用集合必须是使用范围的子集）。下游可用它按需生成资产，不必全量生成；
质量审查也会用它校验片段引用是否声明完整。

### 2.2 片段引用示例

```json
{
  "fragment_id": "f1",
  "mode": "image_to_video",
  "prompt": "Lin Ran walks into the rainy alley",
  "duration": 3.0,
  "asset_ref": "",
  "references": [
    {
      "asset_id": "char_001",
      "role": "identity_reference",
      "view": "front",
      "as_first_frame": false,
      "required": true
    },
    {
      "asset_id": "scene_001",
      "role": "first_frame",
      "view": "front",
      "as_first_frame": true,
      "required": true
    }
  ],
  "first_frame_instruction": "Generate asset scene_001 with prompt: ...; then use it as the first frame and animate: ..."
}
```

- `references[].asset_id` 始终是 PenShot 规范 ID；
- 资产未生成时 `asset_ref` 为空，`first_frame_instruction` 会提示下游先生成参考图；
- 下游改名必须通过 `asset_id_map`，**不要修改 `asset_id`**；
- 角色三视图与道具静帧**不再作为首帧**：只有 `as_first_frame = true` 的场景锚点
  用于图生视频首帧，`asset_ref` 只代表该片段的首帧引用；
- 片段引用未出现在对应资产的 `usage.fragments` 中时，质量审查会记为
  `asset_usage_missing`（major），违规同时带 `fragment_id` 与 `asset_id`。

### 2.3 召回与知识库可观测字段

`prompt_converter_result.json` 的 `metadata.anchor_recall` 记录提示词模板召回统计：

| 字段 | 语义 |
| --- | --- |
| `queries` / `queries_skipped` | 成功构造锚点查询 / 因无锚点跳过的片段数 |
| `hits` / `injected` | 去重后召回条数 / 实际注入条数 |
| `min_score` / `max_score` | 实测检索分数极值（未执行检索时为 `0.0`） |
| `kb` | 知识库快照：模板总数、活跃模板数、legacy 数、跨剧本候选 |
| `status` | 召回结论，见下表 |

`status` 取值：

| 取值 | 含义 |
| --- | --- |
| `hit` / `hit_global` | 同剧本 / 跨剧本命中 |
| `first_run_no_history` / `first_run_global_hit` | 无活跃历史 / 仅跨剧本首次命中 |
| `empty_templates` | 有缓存但全部被排除（例如全部为 legacy） |
| `index_unavailable` / `index_load_failed` | 索引缺失 / 索引加载失败 |
| `cache_index_mismatch` | 缓存与索引数量不一致 |
| `embeddings_unavailable` / `retrieval_error` | 嵌入不可用 / 检索异常 |
| `all_below_threshold` | 检索正常但分数未达阈值 |
| 空串 | 未执行任何检索，不产出召回结论 |

`schema_version = legacy` 的模板默认不参与索引重建与召回（跨剧本召回同样排除）。
迁移脚本只做备份、标记与隔离，不删除底层数据。

## 3. 接入方式 A：直接消费输出（推荐）

下游只运行一次 PenShot，后续全部在本地完成：

```python
def downstream_node(data, image_service, video_service):
    instructions = data["instructions"]
    plan = data["asset_plan"] or instructions["asset_plan"]
    manifest = data["asset_manifest"] or instructions["asset_manifest"] or {}

    # 1) 按 asset_plan 生成尚未回填的资产
    generated = {b["asset_id"]: b["asset_ref"] for b in manifest.get("bindings", [])}
    for asset in plan["assets"]:
        if asset["status"] != "pending":
            continue
        generated[asset["asset_id"]] = image_service.generate(
            prompt=asset["image_prompt"],
            negative_prompt=asset["negative_prompt"],
            size=asset["size"],
            seed=asset["consistency"]["seed"],
        )

    # 2) 按片段 references 调用视频服务
    for package in instructions["route_plan"]["adapted_packages"]:
        first = next(
            (ref for ref in package["references"] if ref["as_first_frame"]),
            None,
        )
        if first is None:
            video_service.text_to_video(package["prompt"])
            continue

        asset_ref = generated.get(first["asset_id"])
        if not asset_ref:
            # 资产未就绪：保留声明式提示词，交由下游继续生成
            video_service.text_to_video(package["prompt"])
            continue

        video_service.image_to_video(
            prompt=package["prompt"],
            first_frame=asset_ref,
            duration=package["duration"],
        )
```

完整可运行示例：[examples/sdk/08_asset_handoff.py](../../examples/sdk/08_asset_handoff.py)（无需 LLM / 图片 / 视频密钥）。

## 4. 接入方式 B：回填 `asset_manifest`

下游生成资产后，可构造清单并随下一次任务提交，让 PenShot 自动解析引用。

### 4.1 清单格式

```json
{
  "schema_version": "0.4.4",
  "task_id": "t1",
  "bindings": [
    {
      "asset_id": "ds_char_001",
      "view": "front",
      "asset_ref": "/cdn/ds_char_001_front.png",
      "model": "flux-pro",
      "seed": null,
      "checksum": "",
      "source": "downstream_image_service",
      "revision": 1
    }
  ],
  "asset_id_map": {
    "char_001": "ds_char_001"
  }
}
```

- `asset_id_map`：PenShot 规范 ID → 下游实际 ID；只有改名时才需要；
- `bindings[].asset_ref`：下游真实图片地址；
- `schema_version` 必须与消费端一致，当前为 `0.4.4`。

### 4.2 REST

```http
POST /api/v1/storyboard
Content-Type: application/json

{
  "script": "剧本内容",
  "language": "zh",
  "asset_manifest": {
    "schema_version": "0.4.4",
    "bindings": [
      {"asset_id": "ds_char_001", "asset_ref": "/cdn/ds_char_001_front.png"}
    ],
    "asset_id_map": {"char_001": "ds_char_001"}
  }
}
```

同步端点 `/api/v1/storyboard/sync` 同样支持。

批量提交时使用与脚本按下标对应的 `asset_manifests`，允许某条为 `null`：

```json
{
  "scripts": ["剧本1", "剧本2"],
  "asset_manifests": [
    {"bindings": [{"asset_id": "ds_char_001", "asset_ref": "/cdn/a.png"}]},
    null
  ]
}
```

### 4.3 Python SDK

```python
agent.breakdown_script(
    script_text,
    asset_manifest=manifest,
)
```

批量：

```python
agent.batch_breakdown(
    scripts,
    asset_manifests=[manifest_1, None],
)
```

### 4.4 MCP

`breakdown_script` 工具已声明 `asset_manifest` 参数：

```json
{
  "script": "剧本内容",
  "language": "zh",
  "asset_manifest": {"bindings": [{"asset_id": "ds_char_001", "asset_ref": "/cdn/a.png"}]}
}
```

## 5. 人工编辑资产提示词

工作流进入人工干预节点时，若已生成 `asset_plan`，界面会展示每个资产的提示词摘要。选择 `[7] EDIT_ASSET` 后可按编号编辑：

- `image_prompt`：角色三视图、道具、场景的正向提示词；
- `negative_prompt`：对应负向提示词；
- 回车表示保持原值，可连续编辑多个资产。

编辑生效后：

1. 修改立即写回 `asset_plan` 与全局契约；
2. 该资产的旧 `asset_ref` 清空、`status` 回到 `pending`；
3. 回填清单中对应的 `bindings` 与 `asset_id_map` 被移除，避免继续使用旧图；
4. 工作流回到 `GENERATE_ASSETS` 重建资产计划，并继续下游分段与提示词转换；
5. 编辑记录累计保存在 `execution.asset_prompt_edits`，并在资产 `metadata` 中写入 `human_edited`、`edit_source`、`edit_revision`。

如果没有资产计划或未修改任何字段，`EDIT_ASSET` 会自动回退为 `CONTINUE`。

## 6. 下游二次修复与溯源

下游可以在调用视频服务前修改提示词、换目标模型，但必须保留溯源信息：

```python
from penshot.neopen.agent.model_adapter import PromptOverride, apply_overrides

apply_overrides(
    adapted_packages,
    [
        PromptOverride(
            target_id="f1",
            field="prompt",
            value="Lin Ran steps into the alley, neon reflections",
            source="downstream_repair",
            revision_id="rev-42",
        )
    ],
)
```

规则：

- 只允许修改提示词、目标模型等白名单字段；
- `asset_ref`、`references`、`asset_id` 不可被覆盖；
- 每次修改写入 `revision_id` / `revision_source` / `parent_id` / `revision`，形成可追溯链。

## 7. 缺失资产与降级规则

| 情况 | 行为 |
| --- | --- |
| 资产为 `pending` | 保留声明式提示词，下游按 `first_frame_instruction` 生成；不阻断主流程 |
| 高一致性/含关键文字片段缺少必需角色资产 | 该片段回退 `text_to_video` |
| 下游提供了 `asset_manifest` | 按 `asset_id_map` → `bindings` 解析真实引用，优先于契约 |
| 下游未提供清单 | 使用契约中已回填的 `asset_ref`；没有则保持声明式引用 |
| `asset_manifest` 版本不匹配 | 视为无效回填，保持计划状态，不抛阻断异常 |
