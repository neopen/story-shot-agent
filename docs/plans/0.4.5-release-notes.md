## 4. 升级注意事项

1. **版本号未变**：`pyproject.toml` 与 `penshot/__init__.py` 仍为 `0.4.4`（最后一个已发布版本）。本批修复未升版，正式发布时统一升到 `0.4.5` 并补齐变更日志，本文档不代替发布动作。
2. **片段 ID 会重编号**：去重/重切后片段按 `frag_001…` 重新编号。消费方若按 ID 关联上游镜头或基线产物，必须读取 `video_splitter_result.metadata["fragment_id_map"]`（含 `shot_id`、原始 `fragment_id`、`source_fragment_ids`），不能假设编号不变。
3. **时长与片段数会变化**：片段时长改为按动作节点确定性重算，合并/重切/截断会改变片段数与总时长（本样本 11→10、34.68s→39.65s）；`≤5.0s` 与 `≥2.5s` 不变量保持不变。依赖旧时长做排期的下游需重新校准。
4. **风格字段语义收紧**：`resolved_by` 不再出现 `no_signal`，无信号时记 `default_fallback` 并写入 `defaults_applied`；`genre` 仍允许为空。读取 `no_signal` 做判定的外部逻辑需改为判断 `resolved_by` 与 `provenance.source`。
5. **音频新增语言字段**：`AIAudioPrompt` 新增 `dialogue_language`（默认 `zh`）；中文剧本会移除英文台词描述，并把非中文 `voice_description` 映射为中文。0.4.5 **不包含** `dialogue_cues`，该结构留给 0.5 迁移；旧产物可正常读取，缺失字段按剧本语言补齐。
6. **资产回填受保护**：`status=generated`、`asset_ref` 非空、`human_edited=True`、清单 `revision>0` 的资产不会被服装回填覆盖。无 `asset_manifest` 时按未编辑处理并记 `info`；若下游依赖“总能回填”，需先补齐清单 revision。
7. **输出兼容性**：`prompt_converter_result.json` 与 `asset_plan.json` 只新增可选字段（`dedupe_report`、`fragment_id_map`、`duration_report`、`dialogue_language`、provenance 扩展字段），未删除既有字段。
8. **真实 E2E 未执行**：本版验证为两轮产物离线回放 + 本地全量回归，未调用任何图像/视频/音频生成 API。上线前应在目标环境跑一次联网全链路，重点核对模型侧对重编号片段、`dialogue_language` 与风格前缀的实际消费。
9. **已知未覆盖项**：3 个知识库集成查询用例因缺少预置向量索引被跳过；仓库级 `ruff format --check` 仍有 223 个历史未格式化文件，均不属于 0.4.5 改动范围。三份外部未跟踪文档未修改、未提交。
