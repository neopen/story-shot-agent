# 0.5 开发路线图与设计

## 1. 版本定位

0.5.0 的主题是“导演级指令层收口”：

- 先固定 PenShot 边界，把生成、音频、剪辑、成片审核切给下游
- 再把分镜从“固定阈值切分”升级为“语义节拍切分”
- 引入节奏控制与情感驱动，让提示词具备导演意图

边界定义以 `docs/PenShot 边界与职责.md` 为准。

## 2. 现状与差距

| 能力 | 现状 | 差距 |
| --- | --- | --- |
| 多模型适配 | 0.4.0 已有能力表与适配层，0.4.3 已接路由 | 选型语义越界，需改为兼容性建议 |
| 结构化相机 | 0.4.3 已完成 `CameraControl` | 运镜只由关键词推导，未与情绪联动 |
| 语义分镜 | 仍按固定时长阈值切分，超长片段截断 | 缺少叙事节拍边界，截断会丢失内容 |
| 节奏控制 | 只有单片段时长约束 | 缺少全片节奏档位与相邻时长约束 |
| 情感驱动 | 情绪仅用于时长估算 | 未进入视觉风格与运镜 |
| 音频 | `prompt_converter` 生成含 TTS 执行参数的音频提示词 | 执行参数越界；台词与氛围意图保留，改为 `dialogue_cues` + `audio_context` 交接 |
| 资产 | 可声明规格，也可调用图像客户端 | 执行越界，应收敛为只声明 |
| 超长剧本 | 已有 chunker/validator，但未接入工作流 | 0.6.0 处理 |
| 多格式导出 | 仅 JSON | 0.7.0 处理 |

## 3. 目标与非目标

### 3.1 目标

- 所有输出字段的 owner 明确，PenShot 不执行任何下游生成动作
- 片段按叙事节拍切分，固定阈值只作兜底
- 全片节奏可配置，时长约束可验证
- 情绪贯通分镜、提示词与相机控制
- 交接清单可被 PenGen、PenDub 独立消费

### 3.2 非目标

- 视频生成、TTS、音效生成
- 音频同步、唇形对齐
- 剪辑时间线与成片组装
- 成片质量审核与视频 VQA
- 多租户、分布式调度

## 4. 总体设计

### 4.1 数据流

```text
script
  → script_parser
  → shot_segmenter（镜头 + 叙事节拍 + 情绪 + 基础时长）
  → video_splitter（按节拍切分 + 节奏约束 + 时间轴不变量）
  → prompt_converter（视觉提示词 + 相机 + 情绪风格 + 节奏提示 + dialogue_cues）
  → route_model（能力适配 + 兼容性建议）
  → loop_check
  → generate_output（生成 HandoffManifest 并发布 shot_plan.ready）
```

### 4.2 设计原则

1. 情绪与节拍只在分镜阶段推断一次，后续只消费
2. 节奏调整只做容差内微调，显式时长优先
3. 任何时长变化后必须重建时间轴，保证无间隙、无重叠
4. 新增输出字段先登记 owner，再进入契约
5. 下游模块不回读剧本，只消费交接清单
6. 音频只交接意图（台词、氛围、时间），不携带 TTS 执行参数；原生音频与独立配音两条路径共用同一份 cues

## 5. 里程碑

### M0.5.0.0 边界收口

目标：先把不该 PenShot 做的事切出去。

交付：

1. 字段归属表与 `HANDOFF_FIELD_OWNERS` 常量映射
2. `dialogue_cues` 契约（`DialogueCue`：cue_id、fragment_id、speaker、text、emotion、start_offset、end_offset、expected_speech_duration），`audio_prompt` 默认关闭并标记 deprecated
   - 偏移为片段内秒数，全局时间码由时间轴派生
   - 场景级 `audio_context` 纳入 HandoffManifest
3. `RoutePlan` 改为兼容性建议：
   - `required_capabilities`
   - `recommended_model`
   - `requires_confirmation`
   - `audio_path`（`native | dub` 建议，最终执行归下游）
   - 旧 `target_model` 保留别名
   - 能力表新增 `native_audio` 维度，补齐原生音频模型注册
4. 资产执行器移出默认路径，默认配置不实例化图像客户端
5. `HandoffManifest` 与 `HandoffSink` 协议：
   - `NullHandoffSink` 默认实现
   - `InMemoryHandoffSink` 测试实现
   - 事件名 `shot_plan.ready`
6. 边界测试：
   - 默认工作流无下游客户端实例化
   - 输出字段集合与 owner 表一致
   - 交接清单可序列化、可消费
   - 音频迁移行为正确（cue 偏移合法、无 TTS 执行参数、氛围音透传）

验收：

- 默认工作流不产生任何图像、视频、音频网络调用
- 契约中不存在未登记 owner 的输出字段
- 旧字段仍可解析，迁移说明完整

### M0.5.0.1 契约与配置

目标：为语义分镜、节奏、情感提供数据基础。

交付：

- `ShotInfo`：`emotion`、`beat_id`
- `VideoFragment`：`emotion`、`beat_id`、`pacing_hint`
- `AIVideoPrompt`：`emotion`、`pacing`、`dialogue_cues`
- `DialogueCue` 模型
- `HandoffManifest`（含场景级 `audio_context`）
- `pacing` 配置段
- `CONTRACT_SCHEMA_VERSION = "0.5.0"`

配置示例：

```yaml
pacing:
  default_profile: "medium"
  total_duration_tolerance: 0.1
  profiles:
    fast:
      target_avg: 2.5
      max_fragment: 4.0
      max_adjacent_delta: 1.0
    medium:
      target_avg: 3.5
      max_fragment: 5.0
      max_adjacent_delta: 1.5
    slow:
      target_avg: 4.5
      max_fragment: 5.0
      min_key_fragment: 3.0
      max_adjacent_delta: 1.5
```

验收：

- 新旧契约往返序列化通过
- 配置缺失时使用默认档位
- 版本号与测试字面量同步

### M0.5.0.2 语义分镜

目标：按叙事节拍切分，而不是机械按 5 秒截断。

设计：

1. `shot_segmenter` 输出 `narrative_beats`：
   - `beat_id`
   - 边界描述
   - 目标时长
2. `video_splitter` 优先在节拍边界切分
3. 单个节拍超过 5 秒时退化为固定切分
4. 退化切分后必须调用时间轴重建
5. 无节拍信息时保持当前行为

节拍边界来源优先级：

1. 分镜 LLM 输出
2. 动作动词与对话切换规则
3. 场景切换
4. 固定阈值兜底

验收：

- 有节拍信息的镜头，至少 80% 在节拍边界切分
- 所有片段不超过 5 秒
- `time_gap` 与 `time_overlap` 为 0

### M0.5.0.3 节奏控制

目标：让全片时长分布符合导演节奏。

设计：

- 节奏档位：`fast` / `medium` / `slow`
- 分镜阶段按档位分配基础时长
- 分割阶段校验相邻时长差与总时长容差
- 只在容差内微调，不做整体重排
- 显式 `duration_override` 优先级最高

约束：

- 单片段 1–5 秒
- 总时长相对目标偏差不超过 10%
- 相邻片段时长差不超过档位上限
- 含台词片段：预计朗读时长 ≤ 片段时长（中文按 4–5 字/秒估算）
- 时间轴连续

验收：

- 三个档位的时长分布符合配置
- 显式时长不被覆盖
- 含台词片段无朗读时长溢出
- 调整后无间隙、无重叠

### M0.5.0.4 情感驱动

目标：情绪进入视觉风格与运镜，而不是只影响时长。

情绪词表与音频情绪保持一致：

| 情绪 | 色调 | 光照 | 运镜倾向 |
| --- | --- | --- | --- |
| neutral | 中性 | 自然光 | 静态 / 缓慢推 |
| joy | 暖色 | 高调 | 轻柔移动 |
| sadness | 冷色低饱和 | 低调 | 缓慢拉/移 |
| anger | 高对比暖红 | 硬光 | 手持 |
| fear | 冷暗 | 低调 | 手持/俯仰 |
| surprise | 高对比 | 闪光感 | 快速推拉 |

设计：

- 分镜阶段写入 `ShotInfo.emotion`
- 片段继承 `VideoFragment.emotion`
- 转换阶段映射风格提示，并调整相机强度
- 低置信度或缺失时回退 `neutral`
- 显式风格优先，不被情绪覆盖

验收：

- 情绪标签覆盖率不低于 90%
- 缺失情绪全部回退 `neutral`
- 同一情绪在不同片段的风格映射一致

## 8. 验收指标

- `time_gap` / `time_overlap`：0
- 片段时长：全部在 1–5 秒
- 节奏偏差：不超过 10%
- 情绪覆盖率：不低于 90%
- 语义切分命中率：不低于 80%
- 含台词片段朗读时长溢出：0
- 默认工作流下游调用：0

## 9. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| LLM 节拍边界不稳定 | 规则回退 + 单节拍最大时长兜底 |
| 节奏调整扭曲内容 | 只做容差内微调，显式时长优先 |
| 情绪误判 | 低置信度回退 neutral，不覆盖显式风格 |
| 契约破坏下游 | 新字段全部可选，旧字段保留一个版本 |
| 边界再次被突破 | 字段 owner 表 + 默认路径导入测试 + PR 检查清单 |
| 台词朗读时长估算偏差 | 按 4–5 字/秒保守估算，溢出时优先延长片段或节拍内重切 |
| 原生音频跨片段音色不一致 | 需统一音色时建议 dub 路径，`requires_confirmation` 交用户确认 |
