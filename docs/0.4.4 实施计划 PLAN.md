## 3. M0 阈值校准门禁（独立里程碑）

### 3.1 为什么必须独立

AC-041（`hits > 0` → `status=hit`）与 AC-042（全部低于阈值 → `all_below_threshold`）都依赖一个具体数值。若阈值未定，测试只能写"任意常数 + 自证"，无法证明生产配置下行为正确。因此把"实测 → 定值 → 落常量 → 跑单测"作为一个原子门禁，M5 只做接线，不重新发明数值。

### 3.3 T-0001 校准脚本规格

CLI：

```
python scripts/calibrate_recall_threshold.py \
  --output-dir data/output/SN2183078837410690460926/TSK21830726110914081668 \
  --base-dir data/embedding/prompt_templates \
  --script-id SN2183078837410690460926 \
  --top-k 1 \
  --report data/output/calibration/recall_threshold_<ts>.json
```

执行步骤（全程只读，不写模板目录与索引目录）：

1. 读取 `script_parser_result.json`，用 `ParsedScript.model_validate` 反序列化（顶层键为 `metadata/title/characters/scenes/global_metadata/stats`）；若字段漂移导致校验失败，脚本必须报错退出，**不得**用空对象继续；随后调用**新增的纯函数** `ScriptParserAgent.build_contract_from_parsed(parsed_script, script_id)` 重建契约（从 `process_with_contract` 中抽取，不触发 LLM）。
2. 读取 `shot_segmenter_result.json` 与 `video_splitter_result.json`；对每个片段调用 `build_fragment_anchor_query(fragment, shot_sequence, contract)`；记录 `queries`（成功构造）与 `queries_skipped`（空查询）。
3. 读取 `templates_cache.json`（样本 127 条），**排除 `added_at` 为 2026-11-09 的本轮新增 11 条**，得到迁移前的 116 条历史基线（本轮检索发生时这 11 条尚不存在，纳入会自污染）；仅取 `metadata.schema_version != "legacy"` 的条目，构造 `Document(text=prompt, metadata=sanitize(metadata))`，用 `VectorStoreIndex.from_documents(..., embed_model=settings)` 建**内存索引**；**禁止** `persist_dir` / `storage_context.persist()`。
4. 逐条查询 `similarity_top_k=1`，记录 `score`、命中模板 `hash`、`script_id`。
5. 计算 `min` / `P50`（`statistics.median`）/ `max`；输出表格与报告 JSON，报告包含：`embedding_model_name`、`embedding_dimensions`、`template_count`（116）、`excluded_current_run`（11）、`legacy_count`（0）、`index_docs_before`（样本为 11，用于记录回归现状）、`queries`、`scores[]`；报告开头 MUST 断言 `template_count == 116`、`legacy_count == 0`（迁移未执行），否则退出码 `3`。
6. 退出码：查询数 < 11 或嵌入模型不可用 → `2`（不产出阈值建议）。

约束：

- 不调用 reranker、不调用 LLM、不写 `data/embedding/prompt_templates/` 下任何文件。
- 必须使用与生产一致的嵌入配置（`settings.embed.default`）；报告中记录模型名，若与模板入库时的模型不一致，结论无效（见 §10 R1）。

### 3.4 T-0002 判定规则

- 目标阈值：`min_score = max(0.45, floor(P50 × 20) / 20)`。
- `P50 < 0.45`：阈值固定 `0.45`，并在报告与日志中标注"模板与查询语义不匹配"，**不得**继续下调（AC-066、边界场景）。
- 在计划文档 §3.4 回填实测值，并在 Spec 附录 B 追加一行校准记录（只记录数据，不改 FR）。

**实测回填（2026-11-09，`data/output/calibration/recall_threshold_20261109_232503.json`）**：

| 项 | 实测值 |
|---|---|
| 基线 / 剔除本轮 / legacy | 116 / 11 / 0 |
| 查询数（跳过） | 11（0） |
| top-1 min / P50 / max | 0.7794 / 0.8127 / 0.8410 |
| 推荐阈值 `max(0.45, floor(P50×20)/20)` | **0.80** |
| 新阈值命中 / 当前 0.70 命中 | 8/11 / 11/11 |
| 嵌入模型 / 维度 / 既有索引维度 | qwen3.7-text-embedding / 1536 / 1536（一致） |
| 既有索引现状文档数 | 11（单文档覆盖回归证据） |
| 复跑（`recall_threshold_20261109_232613.json`） | P50=0.8126，推荐阈值仍为 **0.80**，结论稳定 |

> 环境备注：本机 `NO_PROXY` 含 `[::1]`，会被 httpx 解析为非法端口，导致嵌入客户端初始化失败（`InvalidURL: Invalid port: ':1]'`）。实测命令用 `NO_PROXY="localhost,127.0.0.1"` 覆盖该变量后成功；该问题属于本机环境，不进入业务代码修复范围。

### 3.6 T-0004 纯策略模块与确定性断言

`src/penshot/neopen/prompts/recall_status.py`（无 llama-index 依赖、无 I/O）：

```python
@dataclass
class RecallFacts:
    template_count: int = 0
    active_template_count: int = 0
    legacy_templates: int = 0
    has_index: bool = False
    index_docs: int = 0
    index_load_failed: bool = False
    cache_index_mismatch: bool = False
    embeddings_available: bool = True
    retrieval_error: str = ""
    global_scripts: Dict[str, str] = field(default_factory=dict)

def derive_status(facts, scores, local_hits, global_hits, include_global) -> str
```

状态优先级（与 FR-041/043 对齐，M5 直接复用）：

1. `retrieval_error` 非空 → `retrieval_error`
2. `not embeddings_available` → `embeddings_unavailable`
3. `active_template_count == 0` 且 `template_count > 0` → `empty_templates`
4. `active_template_count == 0` 且 `template_count == 0`：
   - 全局命中 → `first_run_global_hit`
   - 否则 → `first_run_no_history`
5. `index_load_failed` 且无可用索引 → `index_load_failed`
6. `not has_index` → `index_unavailable`
7. `local_hits > 0` → `hit`
8. `global_hits > 0` → `hit_global`
9. `cache_index_mismatch` → `cache_index_mismatch`
10. `scores` 非空且全部低于阈值 → `all_below_threshold`

确定性单测（不联网、不建真实索引，直接喂分数）：

- `test_ac041_hit_when_top_score_above_threshold`：`scores=[1.0]`、`local_hits=1` → `hit`，`hits > 0`。
- `test_ac042_all_below_threshold`：`scores=[0.10, 0.12]`、阈值取常量 → `all_below_threshold`，且诊断包含 `min_score`/`max_score`/`top_k`。
- `test_ac048_status_mapping`：五种失败原因分别映射到五个状态。
- 阈值边界：分数恰等于阈值 → 命中（`>=`），低于 `0.01` → 不命中。

> 这一组断言在 M0 就能证明"阈值已定 + 行为确定"；M5 再用确定性嵌入做一次集成级复验，但不再改数值。

| # | 决策 | 理由 |

## 9. Spec 修订决议（2026-11-09 已确认）

以下三项已确认，Spec 与 PLAN 已同步修订；实现按决议执行，不再作为待决项。

### S-1（已决议：方案 A）FR-066 签名覆盖范围

样本 127 条模板全部 `source=quality_audit_passed`、全部缺 `audit_status`。按 FR-066 的确定性签名统计：

| 签名 | 命中数 | 2026-11-09 | 11-08 | 11-06 | 11-05 |
|---|---|---|---|---|---|
| 污染锚点（手持手帕和湿漉 / 神情焦急 / 湿漉]） | 54 | 5 | 29 | 11 | 9 |
| 互斥打光并存 | 33 | 11 | 0 | 22 | 0 |
| 两者并集 | **71** | 11 | 29 | 22 | 9 |

**决议**：隔离 **71 条**（签名并集），AC-064 期望值改为 71；2026-11-09 的 11 条是其中的子集，必须全部出现在隔离清单中。`source=quality_audit_passed` 且无 `audit_status` 只作为旧模板辅助判定，不单独触发隔离（否则会隔离全部 127 条）。

### S-2（已决议）守恒式与 `legacy_count`

**决议**：`quarantined_count + legacy_count + active_count = template_count_before`（样本为 `71 + 56 + 0 = 127`）。迁移报告 metadata 必须输出这四个字段；`anchor_recall.kb.legacy_templates` 继续作为召回侧计数，含义与 `legacy_count` 一致。

### S-3（已决议）AC-045 重放前置断言

**决议**：AC-045 必须先于迁移执行；用例开始断言 `kb.template_count == 116` 且 `kb.legacy_templates == 0`，否则失败并提示从未迁移备份恢复。校准脚本报告同样记录该前置状态（`template_count` / `legacy_count` / `index_docs_before`）。

## 10. 风险与应对

| # | 风险 | 应对 |
|---|---|---|
