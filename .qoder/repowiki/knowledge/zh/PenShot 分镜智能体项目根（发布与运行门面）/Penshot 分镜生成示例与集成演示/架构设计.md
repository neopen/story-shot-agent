本模块为纯示例集合，无运行时依赖，按“接入形态”横向切分为若干独立脚本：
- 基础用法：`direct_usage.py`、`neopen_demo.py` 展示 `PenshotFunction` 同步/异步/批量/自定义配置/队列控制等 API。
- Web 集成：`web_app.py` 通过 `create_web_app()` 构建 FastAPI 应用，暴露 `/api/generate`、`/api/status/{task_id}`、`/api/result/{task_id}` 等 REST 接口，由 `run_web_app()` 启动 uvicorn。
- A2A 编排：`a2a_integration.py` 定义 `StoryboardA2AAgent`（封装并发信号量 + 任务状态机）和 `A2AOrchestrator`（轮询/最少负载策略），演示多代理分发。
- MCP 协议：`mcp_server_demo.py` 作为 MCP Server，`mcp_client.py` / `mcp_http_client.py` 分别以子进程 JSON-RPC 和 HTTP 两种形式消费工具；`function_calls_data.json` 存放工具定义数据。
- 工作流集成：`langgraph_integration.py`、`workflow_node_demo` 展示将分镜能力嵌入 LangGraph 节点。
- 素材与产物：`script_txt/` 提供不同格式的输入剧本，`json_demo/` 保存各处理链路的 JSON 输出样例。
所有脚本均单向依赖核心包 `penshot.*`，彼此之间无相互导入，可独立运行。
