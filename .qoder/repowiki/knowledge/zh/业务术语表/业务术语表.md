### PenShot
- 定义：项目产品品牌名，指代整个剧本到分镜的 AI 视频提示词生成系统。PyPI 包名为 `penshot`，GitHub 仓库名为 `story-shot-agent`，本地工作区目录为 `video-shot-agent`，三者指向同一项目。
- 别名：penshot、story-shot-agent、video-shot-agent

### neopen
- 定义：组织名和核心领域模块名（`src/penshot/neopen`），承载业务逻辑的核心代码都放在此目录下，包括 agent、task、knowledge、client 等子模块。
- 别名：Neopen

### 分镜
- 定义：影视制作术语，指将剧本分解为镜头级别的视觉描述单元。在本项目中特指 AI 视频模型可理解的 prompt 片段，包含英文视觉描述、负面提示词、时长估计、目标模型、风格参数等结构化信息。
- 别名：shot、storyboard

### 连续性守护
- 定义：PenShot 系统的核心差异化能力，通过多级记忆（短期/中期/长期）+ Chroma 向量检索 + 一致性契约，确保跨片段角色服装、场景、气象、风格的连贯性。当前架构演进方向是从"末端检查"走向"前置约束"。
- 别名：continuity_guardian、连续性体系

### 六智能体流水线
- 定义：PenShot 的核心处理链路，包含六个顺序执行的智能体节点：script_parser（剧本解析）→ shot_segmenter（镜头分割）→ video_splitter（视频分割）→ prompt_converter（提示词转换）→ quality_auditor（质量审计）→ continuity_guardian（连续性守护）。每个智能体都有 rule/llm 双实现。
- 别名：六阶段流水线、multi-agent pipeline

### TaskFactory
- 定义：任务统一入口类，提供 submit/submit_and_wait/batch 等方法，负责任务的创建、入队、状态管理和结果获取。内部协调 AsyncTaskProcessor（后台线程+优先级队列）和 TaskManager（状态机/进度/回调）。
- 别名：任务工厂

### MultiAgentPipeline
- 定义：每任务一个的工作流实例，基于 LangGraph StateGraph 构建，包含 WorkflowOrchestrator（构图）、WorkflowNodes（执行逻辑）、PipelineDecision（条件路由）等组件。每个实例拥有独立的 LLM/embedding/记忆上下文。
- 别名：多智能体工作流、pipeline

### 三级记忆
- 定义：PenShot 的记忆体系分层：短期记忆（当前会话上下文，LangChain message 级）、中期记忆（阶段摘要 summary）、长期记忆（Chroma 向量库文档，跨任务召回）。持久化在 `data/memory/{script_id}/` 目录。
- 别名：memory system、short/mid/long-term memory

### P0/P1/P2 问题分级
- 定义：项目评测报告中的问题严重性分级标准。P0 表示阻断性问题（如 AI 分割器未触发、自动修复未执行），P1 表示重要功能缺失（如短期记忆为空、置信度评分缺失），P2 表示次要问题（如 LlamaIndex 未启用）。
- 别名：问题等级、bug severity

### Phase 3-4
- 定义：项目架构演进阶段的标识。当前处于 Phase 3-4，即"工作流编排成形，连续性体系正从末端检查走向前置约束"。完整路线图：MVP → 多智能体流水线 → 服务化任务化 → 工作流编排 → 连续性系统 → 长剧本记忆 → 平台化成品。
- 别名：演进阶段、architecture phase
